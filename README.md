# OddClicks 📌

Молниеносно быстрое и стильное настольное приложение для Windows для сбора и каталогизации закладок из любых браузеров и приложений в 1 клик.

Построено на **Rust**, **Tauri v2**, встроенной **SQLite (WAL mode)**, **React 19**, **TypeScript** и **Tailwind CSS**.

---

## 🚀 Ключевые возможности

- ⚡ **1-Click Захват из любого браузера**: встроенный легковесный фоновый HTTP-сервер (`127.0.0.1:28765`) и готовый перетаскиваемый букмарклет для Chrome, Edge, Brave, Firefox, Arc, Opera.
- 🖼️ **Автоматический сбор метаданных**: мгновенное сохранение ссылки + фоновое извлечение превью OpenGraph, фавиконок высокого разрешения, заголовков и описаний.
- 💾 **Локальная SQLite база данных**: нулевые задержки, автоматический WAL-режим, хранение данных в `%APPDATA%\OddClicks\oddclicks.db`.
- 🔍 **Мгновенный поиск и фильтрация**: горячая клавиша `Ctrl+K`, группировка по доменам (`github.com`, `habr.com`), коллекциям, тегам и избранному.
- 🎨 **Интерфейс в стиле Fluent / Glassmorphism**: кастомный безрамочный заголовок окна Windows 11 с перетаскиванием, переключение между сеткой превью (Grid) и плотным списком (Dense List).
- 📥 **Импорт закладок**: поддержка загрузки стандартных HTML-файлов закладок из любого браузера.

---

## 🛠️ Запуск в режиме разработки

В терминале PowerShell в папке проекта:

```powershell
npm run tauri dev
```

Команда автоматически запустит локальный Vite сервер и скомпилирует приложение Tauri v2 в нативном окне Windows.

---

## 📦 Сборка релизной версии

Чтобы собрать оптимизированный `.exe` инсталлятор / бинарник:

```powershell
npm run tauri build
```

Готовый файл появится в каталоге `src-tauri/target/release/bundle/nsis/` и `src-tauri/target/release/oddclicks.exe`.

---

## 📌 Использование Букмарклета

1. Запустите приложение **OddClicks**.
2. В приложении нажмите кнопку **«Букмарклет»**.
3. Перетащите кнопку **«📌 Сохранить в OddClicks»** на панель закладок вашего браузера (нажмите `Ctrl + Shift + B`, чтобы открыть панель закладок).
4. На любой интересной странице нажмите на эту закладку — ссылка мгновенно прилетит в OddClicks!
