# Возможности Netami Pin

Состояние реализации: 2 октября 2026 года. Выбранное пользователем направление — **«Редакция»**.

## Библиотека

- Сетка и список, поиск по названию, адресу, описанию, заметке, домену и тегам. Поиск поддерживает кириллицу без учёта регистра; `Ctrl+K` переводит фокус в поле поиска.
- Коллекции, избранное, фильтры по тегам и источникам. Удаление коллекции оставляет её закладки без коллекции.
- Добавление HTTP/HTTPS-ссылки, вставка из буфера, редактирование названия, заметки, коллекции и тегов; копирование адреса и удаление с подтверждением.
- Редактор справа в широком окне, поверх содержимого в узком. Escape закрывает диалог; фокус возвращается к исходному действию.
- HTML-импорт браузерных закладок. Неподдерживаемые адреса пропускаются, существующие ссылки сохраняют пользовательские поля. Импорт сообщает число новых ссылок. Иерархия папок браузера не переносится; массовый импорт не запускает сбор метаданных для всех страниц.
- Фоновое получение заголовка, описания, OpenGraph-превью и значка сайта при обычном добавлении. Страница может запретить загрузку или не иметь метаданных — тогда остаётся заглушка.
- Светлая, тёмная и системная темы; тема и режим просмотра сохраняются на этом компьютере. Шрифты Segoe UI и Georgia берутся из Windows.
- Карточки сохраняют геометрию при наведении и обновлении метаданных. Новые поступления при прокрутке ожидают нажатия «Новые закладки»; в начале списка появляются сразу.
- Ошибка сохранения оставляет введённые данные. Во время обновления результатов существующая библиотека остаётся на экране.

## Windows и данные

По умолчанию закрытие окна скрывает Netami Pin в трей: «Открыть Netami Pin» и «Выйти». В настройках можно отключить сохранение в трее. Повторный запуск показывает существующее окно.

База остаётся в `%APPDATA%\OddClicks\oddclicks.db`. Перед первой миграцией версии 1 приложение создаёт рядом `oddclicks.before-v1.db` через SQLite Backup API, включая данные WAL. Миграция сохраняет закладки, коллекции, заметки, избранное и теги. Копия не перезаписывается при следующих запусках.

Для самостоятельной сборки:

```powershell
npm ci
npm run tauri build
```

Готовая самостоятельная релизная сборка: `src-tauri/target/release/oddclicks.exe`. Она проверена в настоящем WebView2 и с Chrome-расширением. Установщики после `tauri build`: `src-tauri/target/release/bundle/`, если включены соответствующие цели Tauri; установщик в этой реализации не создавался.

Для запуска этой x64-сборки достаточно одного EXE на Windows с установленным **Microsoft Edge WebView2 Runtime**. Интерфейс и SQLite встроены; Node.js, Rust, исходники и отдельный сервер не нужны. WebView2 не входит в EXE: на другом компьютере при его отсутствии установите [Evergreen WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section). База создаётся отдельно в `%APPDATA%\OddClicks`, поэтому перенос EXE не переносит библиотеку.

## Chrome

Расширение сохраняет текущую HTTP/HTTPS-страницу одним нажатием. Передаются адрес и название вкладки, без тегов и коллекции. Обычного popup нет. Служебные страницы Chrome, локальные файлы и другие схемы не поддерживаются.

### Установка и подключение

1. Запустите Netami Pin, откройте «Подключить браузер» и проверьте статус локального сервера.
2. Откройте `chrome://extensions`, включите «Режим разработчика» и нажмите «Загрузить распакованное расширение».
3. Выберите папку `extension/chrome`. Если используете `release/oddclicks-chrome.zip`, распакуйте его в постоянную папку и выберите папку с `manifest.json`. Расширение не устанавливается автоматически при запуске EXE.
4. Откройте настройки расширения через страницу расширений или контекстное меню значка.
5. Скопируйте локальный токен из Netami Pin, вставьте в настройки расширения и нажмите «Подключить». Токен нужен один раз для этого профиля Chrome.
6. Закрепите значок Netami Pin и нажимайте его на страницах, которые хотите сохранить.

Не перемещайте папку распакованного расширения после установки. После обновления файлов нажмите «Обновить» на странице `chrome://extensions`. ZIP создаётся командой `npm run extension:zip`; тесты в архив не включаются.

Архив сохраняется в `release`, которую сборка Vite не очищает. Если значок не виден на панели Chrome, закрепите Netami Pin в меню «Расширения» (значок пазла).

### Очередь и состояния

| Значок      | Значение                                                   |
| ----------- | ---------------------------------------------------------- |
| `…`         | Идёт сохранение                                            |
| `✓`         | SQLite подтвердила сохранение                              |
| `=`         | Ссылка уже есть; пользовательские поля не изменены         |
| `↗` / число | Ссылка ожидает передачи                                    |
| `!`         | Ошибка; пояснение в подписи значка или на странице очереди |

Захват сначала записывается в `chrome.storage.local`, потом отправляется приложению. Очередь переживает закрытие браузера и остановку service worker. Элемент удаляется только после корректного подтверждения с идентификатором закладки.

Повторное нажатие для ожидающего адреса не создаёт второй элемент. Для каждой попытки используется исходный `request_id`: потеря ответа после успешной записи не приводит к дубликату. Повтор такой передачи не восстанавливает закладку, которую пользователь уже удалил.

Передача повторяется при новом захвате, запуске Chrome и примерно раз в минуту, пока очередь непуста. Тайм-аут — 5 секунд. Для передачи должны одновременно работать Chrome и Netami Pin; при закрытом Chrome очередь не отправляется. Браузер может задерживать alarm.

На странице настроек видны подключение, ожидающие ссылки и ошибки; можно повторить передачу или удалить элемент. Неверный токен сохраняет очередь и требует повторного подключения. Постоянная ошибка данных блокирует элемент до ручного повтора или удаления.

Сервер слушает только `127.0.0.1:28765`. Если порт занят, Netami Pin показывает ошибку запуска; расширение оставляет ссылки в очереди. Освободите порт и перезапустите Netami Pin.

## Букмарклет

В «Подключить браузер» раскройте «Альтернативный способ: букмарклет». Перетащите кнопку на панель закладок или скопируйте код в адрес новой закладки.

Букмарклет использует совместимый `/api/add` без токена. Уведомление **«Отправлено»** сообщает только об отправке `no-cors` запроса, а не о записи в SQLite. Настройки безопасности страницы и браузера могут блокировать loopback-запрос. У букмарклета нет устойчивой очереди.

## Границы первой версии

Облачной синхронизации, расширений других браузеров, Native Messaging и публикации в Web Store нет. Расширение не редактирует закладки и не показывает библиотеку.

Для метаданных приложение обращается к сохранённому сайту; резервный источник значков — favicon Google. Это не синхронизация библиотеки, но эти запросы видны соответствующим серверам. Удаление профиля/расширения Chrome удаляет его очередь. Границы проверки указаны в [testing.md](testing.md).
