## Объём и воспроизводимость

- [ ] Выбраны поддерживаемые ОС, минимальные версии, архитектуры и форматы пакетов.
- [ ] Согласованы пользовательские сценарии и известные ограничения.
- [ ] Версии в package/Cargo/Tauri и release notes согласованы.
- [ ] Сборка использует lock-файлы, известные версии Node/Rust и чистое окружение.
- [ ] Git LFS доставил реальные дизайн-файлы, если они нужны в артефакте; тестовые данные и секреты в поставку не попадают.

## Данные и основной сценарий

- [ ] Сохранить из приложения и расширения, найти, изменить, перезапустить.
- [ ] Повторная доставка не создаёт дубль и не восстанавливает удалённую запись.
- [ ] Импорт не перезаписывает неожиданно пользовательские поля.
- [ ] Миграция с каждой поддерживаемой исходной схемы сохраняет библиотеку.
- [ ] Backup согласован с WAL, восстановление реально проверено на тестовой копии.
- [ ] Недостаток места, отказ записи, прерывание и некорректный импорт не приводят к ложному сообщению об успехе.
- [ ] Корзина, восстановление и массовые операции проверены, если входят в выпуск.
- [ ] Переименование OddClicks не потеряло доступ к прежним данным, если входит в выпуск.

## Интерфейс и платформы

- [ ] Изменённые экраны совпадают с принятым дизайном и работают в обеих темах.
- [ ] Клавиатура, фокус, Escape, Cmd/Ctrl, reduced motion и длинный текст проверены.
- [ ] Проверены шрифты без сети, DPI, минимальное окно и несколько мониторов там, где заявлена поддержка.
- [ ] Работают открытие URL, импорт/экспорт через файловый диалог, закрытие окна, трей и повторный запуск.
- [ ] Неподдерживаемое платформой поведение имеет явную альтернативу.

Каждая архитектура — отдельная строка. Браузерный Playwright проверяет web UI. Существующие WebView2/CDP-сценарии подтверждают Windows-путь и не переносятся автоматически на WebKitGTK/WKWebView. Выбранный нативный инструмент сначала проверить коротким экспериментом.

## Расширение и безопасность

- [ ] Очередь переживает закрытие приложения/браузера и перезапуск worker.
- [ ] Ошибки токена, занятый порт, потерянный ответ и повторная передача обработаны.
- [ ] Нажатие реальной кнопки расширения проверено в обычном браузере.
- [ ] Принято решение о legacy `/api/add`, проверена совместимость или инструкция перехода.
- [ ] CSP и capabilities соответствуют нужным действиям, права не выданы шире необходимого.
- [ ] Логи и отчёты не содержат токенов, личных URL и содержимого библиотеки по умолчанию.
- [ ] Ограничены схемы URL, размеры, тайм-ауты и нежелательные направления запросов метаданных.

## Пакет, обновление и восстановление

- [ ] Установщик проверен на системе без dev-окружения, включая зависимости WebView.
- [ ] Подпись приложения для выбранного канала настроена и проверена. Для прямой macOS-поставки запланированы signing/notarization по требованиям канала.
- [ ] Если используется Tauri Updater, проверены отдельная подпись обновления и HTTPS-доставка. Подпись установщика ОС не заменяет подпись updater.
- [ ] Приватные ключи находятся в защищённом хранилище, известен порядок резервирования и восстановления доступа.
- [ ] Обновление предыдущей версии сохраняет данные, настройки и подключение браузера.
- [ ] Пользователь получает понятный результат при недоступной сети и прерванном обновлении.
- [ ] Задокументирована остановка выдачи проблемной версии и выпуск исправления.
- [ ] Старый бинарник не запускается автоматически на несовместимой новой схеме БД. Восстановление backup учитывает изменения пользователя после его создания.
- [ ] Политика удаления приложения и сохранения/удаления личных данных проверена.

Для Linux выбрать поддерживаемые каналы: например, AppImage и пакет для конкретного дистрибутива. Механизм обновления зависит от канала; не обещать работу одного updater для всех пакетов. Mobile обновляется по выбранному мобильному каналу, desktop-updater не считать общей системой для телефона.
