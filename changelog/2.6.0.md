- Choose what to import from a `.kpin` list: every new link has a checkbox, and each section has Import all for its links and feeds. Nothing is saved until you press Accept.
- ⋯ → Import a file… opens an Import window again: drop a file on it or click to choose one, and Koona Pin works out whether it is a list, feeds, bookmarks or a backup.
- Drop a link on the New window to fill in its address; drop a file on it to import the file.
- On macOS, files dropped on the window now reach Koona Pin: lists, feeds, bookmarks and backups can be dropped as on Windows.
