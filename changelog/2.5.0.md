- The Bundle: drag bookmarks, collections, tags and feeds into the Bundle in the corner, then save them as one `.kpin` list or copy it as Markdown. Each collection or tag becomes a section. Open it any time with ⋯ → Share as list….
- One drop zone over your list: drop a link, a `.kpin` list, an OPML file of feeds, a browser's bookmarks or a Koona Pin backup, and Koona Pin works out what it is. ⋯ → Import a file… does the same for a file on disk.
- Share as list… and Import now live in the ⋯ menu; the sidebar has no right-click menus. Files you import have size limits: 8 MB for OPML, 64 MB for browser bookmarks, 256 MB for a backup.
- Importing a list now shows what is inside before anything is saved: its sections, links with their icons, what you already have or have in Trash, and the feeds to follow, with Follow all.
- Switching between library sections is faster.
- The `.kpin` list format is now documented, so other apps can read and write it.
