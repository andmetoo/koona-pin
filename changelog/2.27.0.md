- Tags: tag names are now cleaned of hidden characters such as soft hyphens and zero-width spaces, both new tags and the ones already in your library. A tag that differed from another only by such a character, such as a «coop» with a hidden soft hyphen in it, becomes the same tag, so searching for «coop» finds every bookmark on it. A tag whose name had nothing visible at all is removed. With sync on, every device ends up with the same tags, older versions included.
- Settings → Storage: if the cleaning changed any tag, a «Cleaned tag names» row lists what it did on this device: each tag's old name with its hidden characters shown by their codes, what it became, and, for a merged or removed tag, how many bookmarks it was on.
- Lists: a `.kpin` list's titles, descriptions and tags now lose more of the hidden characters that can make one word pass for another or carry text you never see. Emoji joined from several, like 👩‍💻 and 🏳️‍🌈, now stay whole instead of falling apart, and so do the flags of England, Scotland and Wales and the letters of Persian, Hindi, Sinhala and other scripts that are written with such joiners.
- Importing a list no longer makes a second tag that differs from one you already have only by hidden characters.
- The `.kpin` format now comes with a conformance suite: the files and test cases a reader must pass, published with the specification under CC0, for anyone who writes a tool that reads or writes lists.
