- Sync between your computers, for Supporters. Turn it on in Supporter → Sync between your computers: the first computer becomes the main one, and each other computer joins by signing in with the same email and confirming six digits on the main one. Bookmarks, collections and tags then sync both ways, and a computer that already has a library keeps it and merges it in.
- Sync is encrypted on your computers before anything leaves them. Koona's server only passes it between your devices: it keeps nothing of your library, and nothing waits on it for a computer that is offline.
- The main computer adds and removes computers; every computer is told when one is added. Another computer can become the main one when the main one allows it, and if the main one is lost, you can start over from any computer with a code from your email.
- The Sync window shows each computer with its system, version and last sync, the number of bookmarks, a clock that is off and a version that is too old, with Sync now, Details and Turn off here. Settings → Data has a Sync line too.
- Restoring a full copy brings back the order of your collections in the sidebar.
- A copy saved by a newer Koona Pin, with a source this version doesn't know yet, can be restored.
- The Supporter dialog no longer lists early builds.
- After this update, an earlier version of Koona Pin can't open the library, so update rather than go back.
