- Sync: a computer waiting to be approved by a main computer that is offline can now start over from the waiting screen with a code from your email. Before, Cancel was the only way out.
- Sync: a computer waiting to be approved asks again when the main computer comes back, also after its own connection dropped. Before, the wait could stay stuck.
- Sync: when the waiting computer's request ran out of time or was declined, «Try again» is on the waiting screen. When the main computer never answered, starting over is offered there too.
- Sync: when starting over fails because the code is too old, the Sync window says so and offers to start over again.
