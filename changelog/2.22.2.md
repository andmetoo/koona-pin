- Sync: a computer waiting to be approved is told when the main computer is busy adding another computer, and asks again by itself every 30 seconds. If the main computer stays busy for five minutes, the wait ends and offers «Try again». Before, it said the main computer didn't approve it.
- Sync: when the main computer and the computer waiting to join run versions that can't pair, the Sync window says which one to update. Before, the wait ended as declined or ran out of time.
- Sync: a computer that asked to join too many times says so and offers «Try again» later. Requests that never reached the main computer no longer count, and the message no longer suggests someone may be in between.
- Sync: a computer waiting to be approved asks the new main computer when the main computer changes, and asks again when the main computer reconnects.
- Sync: a connection that stopped answering is noticed within about a minute and made again. A computer that is paused no longer shows as signed out after its sign-in was refreshed, and Start over or «Try again» connects at once instead of waiting.
- Sync: signing in to another account on this computer no longer deletes the sync key of the account that was signed in.
- Sync: the Sync window no longer briefly shows an older state after an action.
- Sync: «Make this the main computer» on a computer that lost its sync key opens Start over. Starting over while sync was not connected keeps the code's sign-in until it connects, instead of failing. If sync doesn't connect in time, the Sync window says the code has expired and offers to start over again.
