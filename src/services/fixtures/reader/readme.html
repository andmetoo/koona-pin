Web

A high productivity web framework for the Go language, with hot code reload, a router, templates and validation built in.

Quick start

go get github.com/example/web/cmd/web
web new myapp
web run myapp

Open your browser at the address it prints and start editing the controllers; the server reloads the code on every change.
